# SOGo-Signatur mit Logo (HTML-Editor) — Freischaltung & Bedienung

## Was freigeschaltet wurde

SOGo hat eine **eingebaute Signatur-Funktion**, die die Signatur speichert und
**automatisch beim Verfassen, Antworten und Weiterleiten** lädt. Sie nutzt
denselben CKEditor wie der normale Mail-Editor — inklusive **Logo/Bild-Einbettung**.

Damit der Signatur-Editor der **HTML-Editor** (mit Logo) ist und nicht nur ein
Plaintext-Feld, wurde in `data/conf/sogo/sogo.conf` systemweit gesetzt:

```
SOGoMailComposeMessageType = html;
```

Diese Datei ist ein persistenter Bind-Mount (`./data/conf/sogo/` → `/etc/sogo/`),
kein Autogenerated-File — die Einstellung ist update-fest. Nach der Änderung:
`docker compose up -d --force-recreate sogo-mailcow`.

> **Verifiziert (2026-07-07):** SOGo lädt die Einstellung, HTML-Signatur-Editor
> aktiv, keine Config-Fehler, `/SOGo/` HTTP 200.

## Steuernde SOGo-Defaults (pro Nutzer über die UI schaltbar)

| Einstellung | Wirkung |
|---|---|
| `SOGoMailComposeMessageType = html` | Signatur- **und** Mail-Editor = HTML (Logo möglich) |
| `SOGoMailUseSignatureOnNew` | Signatur bei **neuer** Nachricht einfügen |
| `SOGoMailUseSignatureOnReply` | Signatur bei **Antwort** einfügen |
| `SOGoMailUseSignatureOnForward` | Signatur bei **Weiterleitung** einfügen |
| `SOGoMailSignaturePlacement` | Signatur **oberhalb** der Antwort oder **unterhalb** des Zitats |

## So legt jeder Nutzer seine Signatur an (Bedienung)

1. Im Webmailer oben rechts auf das **Zahnrad** (Einstellungen).
2. Reiter **Mail** → Abschnitt zum **Konto/Identität** öffnen (Stift/Bearbeiten
   beim Absender `name@mynextdays.dk`).
3. Feld **„Signatur"** — hier ist jetzt der **HTML-Editor** (wie beim Mailschreiben).
   Text tippen, formatieren und über den **Bild-Button das Logo einfügen**.
   - Logo-Tipp: entweder Bild hochladen/einfügen, oder eine öffentlich
     erreichbare Bild-URL verwenden. Bei eingebetteten Bildern hängt SOGo das
     Logo als Inline-Anhang an die Mail (offiziell unterstützt, SOGo #5695).
4. Weiter unten in **Mail-Einstellungen** die Häkchen setzen:
   - **„Signatur bei neuer Nachricht hinzufügen"**
   - **„Signatur bei Antwort hinzufügen"**
   - **„Signatur bei Weiterleitung hinzufügen"**
   - **„Und setze meine Signatur"** → oberhalb der Antwort / unterhalb des Zitats.
5. **Speichern** (oben rechts). Ab jetzt wird die Signatur bei jeder neuen Mail
   und jeder Antwort automatisch geladen.
