## Stack & Aufbau

- **React Native 0.86** — CLI-Projekt mit echten `ios/`- und `android/`-Ordnern, New Architecture, React 19
- **React Navigation 7** — ein Root-Stack über zwei Bottom-Tab-Navigatoren (Gast/Gastgeber)
- **react-native-svg** (Icon-Set), **react-native-keychain** (Auth-Token)
- **Schibsted Grotesk** als native TTFs; Akzentfarbe `#C42B3A`, cremiger Grund `#F6F2EC`
- Design-System 1:1 aus dem Design-Kit portiert (Tokens, Icon-Pfade, Komponenten — `kit.tsx`)

```
App.tsx          GestureHandler → SafeArea → Theme → NavigationContainer → Splash
navigation/      types.ts, GuestTabs.tsx, HostTabs.tsx
screens/         RoleSelect, GuestHome/Discover/Wishlist/Trips/Profile, Host*, ListingDetail, Checkout, Checkin
components/       Splash, ListingCard, ui/ (Icon, kit, Screen)
theme/           tokens.ts (Farben/Typo/Dichte, Light+Dark) + ThemeProvider
ios/ · android/  native Projekte
```

## App-Start & Splash

Beim Start zeigt zunächst der native **LaunchScreen** (iOS-Storyboard) das
myNextDays-Logo auf cremigem Grund — kein „Powered by React Native" mehr. Darüber
legt sich ein **JS-Splash** (`components/Splash.tsx`), der dasselbe Logo zeigt
und nach kurzer Zeit sanft ausblendet, sodass der Übergang ins App-UI ohne
Flackern wirkt. Die App öffnet **direkt in der Gast-Startseite** (wie
Booking/Airbnb), nicht mehr in einer Rollen-Auswahl.

</De>

<En>

## App start & splash

On start the native **LaunchScreen** (iOS storyboard) first shows the
myNextDays logo on a creamy background — no more "Powered by React Native". On top
sits a **JS splash** (`components/Splash.tsx`) that shows the same logo
and gently fades out after a short while, so the transition into the app UI feels
flicker-free. The app opens **directly on the guest home screen** (like
Booking/Airbnb), no longer on a role selection.

</En>

## Gast-Startseite (Booking × Airbnb)

Der erste Tab **Erkunden** (`GuestHome.tsx`) ist eine Discovery-Startseite, die
die Stärken beider Vorbilder im myNextDays-Look mischt:

| Abschnitt | Vorbild |
| --- | --- |
| Reiter Aufenthalte · Erlebnisse · Services (mit „NEU"-Badges) | Airbnb |
| Such-Box Ort / Datum / Gäste + „Suche"-Button | Booking |
| Kategorie-Chips (Strand, Natur, Stadt …) | beide |
| „Suche fortsetzen" (zuletzt gesuchte Orte) | Booking |
| Beliebte Unterkünfte (Querscroll, „Gäste-Favorit", Herz) | Airbnb |
| myNextDays+ Treue-Banner | Booking Genius |
| Angesagte Reiseziele (große Stadt-Karten) | beide |
| Wochenend-Angebote (Hotelkarten mit Score) | Booking |

Tippen auf eine Unterkunft öffnet `ListingDetail`.

</De>

## Guest home screen (Booking × Airbnb)

The first tab **Explore** (`GuestHome.tsx`) is a discovery home screen that
mixes the strengths of both models in the myNextDays look:

| Section | Model |
| --- | --- |

| Popular stays (horizontal scroll, "guest favorite", heart) | Airbnb |
| myNextDays+ loyalty banner | Booking Genius |
| Trending destinations (large city cards) | both |
| Weekend deals (hotel cards with score) | Booking |

Tapping a stay opens `ListingDetail`.

## Backend-Anbindung

Ruft dieselbe `/api/v1`-Schnittstelle wie die Web-App. Basis-URL in
`lib/config.ts`: iOS-Simulator → `localhost:8000`, Android-Emulator →
`10.0.2.2:8000`, echtes Gerät → LAN-IP. Auth-Token via Keychain (`lib/auth.ts`).
Aktuell live angebunden: **Inserate** (`/properties`, Fallback auf Demo-Daten);
die übrigen Screens nutzen noch Demo-Inhalte.

</De>

<En>

## Backend integration

Calls the same `/api/v1` interface as the web app. Base URL in
`lib/config.ts`: iOS simulator → `localhost:8000`, Android emulator →
`10.0.2.2:8000`, real device → LAN IP. Auth token via Keychain (`lib/auth.ts`).
Currently wired live: **listings** (`/properties`, falls back to demo data);
the remaining screens still use demo content.

</En>
